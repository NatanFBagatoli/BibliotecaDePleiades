Bem Vindo à Biblioteca de Plêiades!

O que é a Biblioteca de Plêiades?

A Biblioteca de Plêiades é um projeto pessoal criado para organizar, estudar e compartilhar conhecimentos relacionados à programação e a conhecimentos gerais.

Aqui estão reunidos conteúdos sobre diferentes linguagens e tecnologias, como C#, Python, JavaScript, HTML e CSS, além de conceitos de lógica de programação, orientação a objetos, matemática aplicada à programação e outros assuntos relacionados ao desenvolvimento.

A ideia não é apenas guardar informações, mas transformar o aprendizado em algo prático. Por isso, a biblioteca também reúne exercícios, exemplos de código, projetos e anotações, permitindo acompanhar a evolução dos conhecimentos ao longo do tempo.

Explore as seções, consulte os conteúdos e acompanhe a evolução da Biblioteca de Plêiades.

Introdução

Descrição sobre a introdução ao conteúdo de C#.

public class ExercicioWriteLine
{
    public static void ExecutarWriteLine()
    {
        //1. WriteLine x Write
        Console.WriteLine("Hello World1");
        Console.WriteLine();
        Console.Write("Hello World2");
        Console.WriteLine();

        //2. Concatenação com +
        Console.WriteLine("Hello" + " " + "World");

        //3. Caracteres de escape
        Console.WriteLine("Linha 1\nLinha 2");
        Console.WriteLine("Nome:\tJoão");
        Console.WriteLine("Ele disse: \"Olá!\"");
        Console.WriteLine("C:\\pasta\\arquivo.txt");

        //4. Expressoes aritméticas direto no WriteLine
        Console.WriteLine($"2 + 2 = {2 + 2}");
        Console.WriteLine(4 + 4);
        Console.WriteLine($"5 - 4 = {5 - 4}");
        Console.WriteLine(10 - 5);
        Console.WriteLine($"5 * 5 = {5 * 5}");
        Console.WriteLine(3 * 3);
        Console.WriteLine($"12 / 4 = {12 / 4}");
        Console.WriteLine(12 / 3);

        //5. Formatação composta
        Console.WriteLine("Nome: {0}, Idade: {1}, altura: {2}", "João", 19, 1.80);

        //6. ReadLine
        Console.WriteLine("===== FIM DO PROGRAMA =====");
        Console.Write("Pressione Enter para sair...");
        Console.ReadLine();
    }
}

Lógica de programação

Descrição sobre a lógica de programação no conteúdo de C#.

Exercício de declaração de variáveis com diferentes tipos primitivos: string, char, int, long, float, double, decimal, bool, byte, short, uint, ulong, sbyte e ushort.

public class ExercicioVariaveis
{
    public static void ExecutarVariaveis1()
    {
        string nome = "Natan";
        char inicial = 'N';
        int idade = 22;
        long matricula = 123456789;
        float altura = 1.80f;
        double mediafinal = 8.5;
        decimal mensalidade = 476.90m;
        bool matriculado = true;
        byte qntddisciplinas = 6;
        short datadenasc = 2004;
        uint codigoturma = 3434;
        ulong idsistema = 9876543210;
        sbyte diffidade = -2;
        ushort maxalunos = 46;

        Console.WriteLine("===== CADASTRO DO ESTUDANTE =====");
        Console.WriteLine();
        Console.WriteLine($"Nome: {nome}");
        Console.WriteLine($"Inicial: {inicial}");
        Console.WriteLine($"Idade: {idade}");
        Console.WriteLine($"Matrícula: {matricula}");
        Console.WriteLine($"Altura: {altura} m");
        Console.WriteLine($"Média final: {mediafinal}");
        Console.WriteLine($"Mensalidade: R$ {mensalidade}");
        Console.WriteLine($"Está matriculado?: {matriculado}");
        Console.WriteLine($"Quantidade de disciplinas: {qntddisciplinas}");
        Console.WriteLine($"Ano de nascimento: {datadenasc}");
        Console.WriteLine($"Código da turma: {codigoturma}");
        Console.WriteLine($"Identificador do sistema: {idsistema}");
        Console.WriteLine($"Diferença de idade: {diffidade}");
        Console.WriteLine($"Máximo de alunos: {maxalunos}");
        Console.WriteLine();
    }
}
