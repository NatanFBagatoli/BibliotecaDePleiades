2x² − 7x + 3 = 0

a = 2, b = −7, c = 3

b² − 4ac ⇒ Δ = 49 − 4·2·3 ⇒ 49 − 24 = 25

(−b ± √Δ) / 2a ⇒ (7 ± √25) / 4 ⇒ (7 ± 5) / 4 ⇒ 12/4 = 3 ou 2/4 = 1/2

Raízes: x₁ = 3 e x₂ = 1/2

Termos

Equação com 3 termos ⇒ (ax² + bx + c = 0) → resolve com Bhaskara ou soma e produto.

Equação com 2 termos:

  1. Falta o termo B ⇒ (ax² + c = 0) → isola e tira a raiz.
    x² − 36 = 0 ⇒ x² = 36 ⇒ x = ±6
  2. Falta o termo C ⇒ (ax² + bx = 0) → fatoração colocando x em evidência.
    x² − 6x = 0 ⇒ x(x − 6) = 0 ⇒ x = 0 ou x = 6

Equação com 1 termo ⇒ (3x² = 0) ⇒ x² = 0 ⇒ x = 0. Quando sobra só um termo com x (ax² ou bx), a solução é x = 0. Se sobrar só um número (sem x), como 7 = 0, a equação não tem solução (sentença falsa).

Método da adição

Se duas quantidades são iguais, podemos somá-las ou subtraí-las membro a membro e a igualdade continua valendo.

Caso 1 — SOMAMOS

1ª equação: +y (coeficiente +1)
2ª equação: −y (coeficiente −1)
São opostos, então somando os y se cancelam:
x + x = 2x  |  y − y = 0  ⇒  2x + 0

Caso 2 — SUBTRAÍMOS

(x + 2y) = 11 e (x − y) = 2
1ª: +x  |  2ª: −x
São iguais; subtraindo, os x se cancelam:
x − x = 0  |  2y + y = 3y  ⇒  0 + 3y

Regra de ouro: a escolha de qual incógnita eliminar é decidida pela estrutura do sistema. No caso 1 poderíamos escolher entre eliminar x ou y; no caso 2 somos forçados a eliminar apenas o x.

Geometria plana: áreas e perímetros

Perímetro é a medida do contorno de uma figura.
P = 8 + 5 + 8 + 5 ⇒ P = 26 m

Área é o tamanho da superfície ocupada pela figura.
A = 8 · 5 ⇒ A = 40 m²

Quadrados

P = 4L
A = L²
Exemplo: L = 6 cm ⇒ P = 4·6 = 24 cm  |  A = 6² = 36 cm²

Retângulos

P = 2(b + h)
A = b·h
Exemplo: b = 6 cm, h = 4 cm ⇒ P = 2(6+4) = 20 cm  |  A = 6·4 = 24 cm²

Triângulos

A = (b·h) / 2

Um retângulo possui comprimento de 12 cm e largura de 7 cm. Qual é seu perímetro?
