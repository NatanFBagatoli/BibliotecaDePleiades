## Termos

Equação com 3 termos ⇒ (ax² + bx + c = 0) → Se resolve com bhaskara ou soma e produto

Equação com 2 termos:
1. Falta o termo B ⇒ (ax² + c = 0) → Se resolve isolando e tirando a raiz, exemplo:
x² - 36 = 0 ⇒ x² = 36 ⇒ x = ±6

2. Falta o termo C ⇒ (ax² + bx = 0) → Se resolver por fatoração colocando x em evidência, exemplo:
x² - 6x = 0 ⇒ x(x-6) = 0 ⇒ x = 0 ou x = -6

Equação com 1 termo ⇒ (3x² = 0) = 2x² = 0 ⇒ x² = 0 ⇒ x = 0 → quando sobra só um termo com X seja ele ax² ou bx,
a solução é x = 0. Mas se sobrar só um número (sem x), a equação não tera uma solução (7 = 0 → sentença falsa)

## Metodo da adição

Se duas quantidades são iguais, podemos somá-las ou subtraí-las membro a membro e a igualdade continua valendo

# Caso 1: ⇒ → SOMAMOS
1. Na 1ª equação: +y (coeficiente +1)
1. Na 2ª equação: -y (coeficiente -1)
eles são opostos, então, se somarmos as equações, os y se cancelam 
x + x = 2x e y - y = 0 ⇒ 2x + 0 
2. Na 1ª equação: +x (coeficiente +1)
2. Na 2ª equação: +x (coeficiente +1)
eles são iguais, então, se subtraímos as equações, os x se cancelam 
x - x = 0 e y + y = 2y ⇒ 0 + 2y
# Caso 2: (x + 2y) = 11 e (x - y) = 2 → SUBTRAÍMOS
1. Na 1ª equação: +x (coeficiente +1)
1. Na 2ª equação: -x (coeficiente +1)
eles são iguais, se subtraímos, teriamos x + x = 2x e não eliminariamos nada
x - x = 0 e 2y + y = 3y ⇒ 0 + 3y
2. Na 1ª equação: +2y (coeficiente +2)
2. Na 2ª equação: -y (coeficiente -1)
eles não são iguais nem opostos, são diferentes, então, mesmo somando ou subtraindo, o y não sumiria
2y + (-y) = y e 2y - (-y) = 3y
